Fillvisa OS v1.0.0: Going Open Source, Self-host, and more

Junaid Khan August 23, 2026

Today, we're releasing Fillvisa OS v1.0.0 - the first official release of the open-source edition of Fillvisa.

This is an important milestone for us. Fillvisa started with a simple goal: make immigration paperwork more accessible, less frustrating, and easier to understand. Open sourcing Fillvisa is the next step toward that goal.

We wrote more about why we're taking this direction in Fillvisa is now Open Source.

Introducing Fillvisa OS

Fillvisa OS is the open-source edition of Fillvisa.com.

The source code is now publicly available on GitHub:

github.com/athos2113/fillvisa-os

Fillvisa.com will continue to be the hosted version that anyone can use directly in their browser. Fillvisa OS gives developers, organizations, nonprofits, and technically inclined users another option: run and customize the software themselves.

With Fillvisa OS, you can:

  • Self-host Fillvisa on your own infrastructure.
  • Inspect the source code and understand exactly how the application works.
  • Fork the repository and customize Fillvisa for your own use case.
  • Build on top of Fillvisa instead of starting an immigration-form experience from scratch.
  • Run an independent version while continuing to benefit from future Fillvisa OS releases.

The goal is for Fillvisa.com and Fillvisa OS to complement each other: one provides an immediately accessible hosted experience, while the other provides transparency, control, and the ability to build.

Version 1.0.0

We're calling this release Fillvisa OS v1.0.0.

It's our starting point for treating the open-source project as a first-class Fillvisa product with its own releases and version history.

As Fillvisa OS evolves, we'll publish new versions with improvements, new functionality, fixes, and changes to the underlying project.

You can follow the repository on GitHub for the latest source code:

Fillvisa OS on GitHub →

A New Changelog Tag: Releases

You'll also notice a new tag here on the Fillvisa Changelog:

Releases

The Releases tag will be used exclusively for Fillvisa OS release announcements.

Whenever we ship a notable new version of the open-source project, we'll document it here - starting with v1.0.0.

This also gives each of our changelog tags a clearer purpose.

Releases

Posts about Fillvisa OS releases.

For example:

  • Fillvisa OS v1.0.0
  • Fillvisa OS v1.1.0
  • Major changes between open-source versions
  • Release-specific migration or upgrade information

Added

Something new has been introduced across Fillvisa Free, Fillvisa OS, or Fillvisa Plus.

This can include:

  • New immigration forms
  • New features
  • New workflows
  • New product capabilities

Fixed

We've fixed a bug or problem in Fillvisa Free, Fillvisa OS, or Fillvisa Plus.

These posts will cover fixes that improve reliability and correct unexpected behavior.

Update

We've improved or enhanced something that already exists across Fillvisa Free, Fillvisa OS, or Fillvisa Plus.

This might include:

  • UI improvements
  • Better form experiences
  • Performance improvements
  • Workflow enhancements
  • Changes to existing functionality

Together, these tags should make it much easier to follow what is changing across the Fillvisa ecosystem.

What's Next

v1.0.0 is only the beginning.

By making Fillvisa open source, we're giving developers and organizations a foundation they can inspect, self-host, customize, and build upon.

At the same time, we'll continue improving the hosted Fillvisa products and bringing those improvements back into the broader Fillvisa ecosystem where appropriate.

If you'd like to explore the code, self-host Fillvisa, or simply follow the project as it develops, you can find everything on GitHub:
